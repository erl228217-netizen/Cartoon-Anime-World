CARTOON & ANIME WORLD — حزمة التشغيل والتجهيز

ما تم تجهيزه:
- الواجهة الأصلية مع نموذج تسجيل/دخول بالبريد وكلمة المرور عبر Firebase Authentication.
- زر دخول Google الحقيقي عبر Firebase Google Provider.
- ربط Firestore لإضافة وعرض وحذف بيانات الأعمال من لوحة المدير.
- مشغل HTML5 يقبل رابط MP4 آمن HTTPS عند وجوده في بيانات العمل.
- الدفع غير مفعل عمدًا؛ لا توجد معاملات مالية أو تفعيل اشتراكات مدفوعة حقيقي.

مهم: هذه الحزمة ليست جاهزة لتسجيل الدخول الحقيقي قبل إعداد مشروع Firebase الخاص بك. لا يمكن إنشاء مشروعك أو الموافقة على OAuth نيابة عنك.

خطوات الإعداد المطلوبة مرة واحدة:
1) افتح https://console.firebase.google.com/ وأنشئ مشروعًا (قد تتوفر حدود مجانية حسب شروط Firebase).
2) أضف Web App داخل المشروع وانسخ إعدادات firebaseConfig إلى firebase-config.js.
3) من Authentication > Sign-in method فعّل Email/Password وGoogle.
4) من Authentication > Settings > Authorized domains أضف نطاق الاستضافة الذي ستستخدمه.
5) أنشئ Cloud Firestore Database. انشر محتوى firestore.rules بعد استبدال YOUR_ADMIN_EMAIL@example.com ببريد المدير نفسه.
6) في firebase-config.js ضع بريد المدير نفسه داخل ADMIN_EMAILS. لا تضع بيانات سرية في هذا الملف؛ إعدادات Firebase للويب عامة بطبيعتها ويجب حماية البيانات بقواعد Firestore.
7) شغّل المشروع من استضافة HTTPS أو خادم محلي، وليس بفتح index.html مباشرة، لأن وحدات JavaScript وGoogle OAuth تحتاج origin صالحًا.

التشغيل المحلي للتجربة (بعد إعداد Firebase):
- افتح مجلد المشروع في VS Code وشغّل Live Server، أو استخدم أي خادم محلي ثابت.
- لا ترفع ملفًا يحوي بيانات خاصة، ولا تشارك كلمة مرور أو رموز تحقق.

ملاحظات مهمة وحدود النسخة:
- دخول Google والبريد لن يعمل قبل وضع إعدادات Firebase وتفعيل المزودين وإضافة النطاق.
- لوحة المدير تحفظ بيانات الأعمال في Firestore، ويتم تحميل السجلات العامة إلى كتالوج الموقع بعد تهيئة Firebase وتسجيل حالة المصادقة.
- الحذف والإضافة من لوحة المدير تتطلب أن يطابق بريد المستخدم قائمة المدير في القواعد وفي firebase-config.js. لا تعتمد على إخفاء الزر كوسيلة حماية؛ قواعد Firestore هي الحماية الأساسية.
- مشغل الفيديو الحالي يدعم روابط MP4 مباشرة فقط؛ روابط منصات البث الخارجية وHLS تحتاج مشغلًا/تكاملًا إضافيًا. لا تستخدم إلا فيديوهات تملكها أو لديك ترخيص واضح لها.
- لا توجد بعد إدارة كاملة للمواسم والحلقات، صلاحيات متعددة، استعادة كلمة المرور المخصصة، حدود الأجهزة، أو دفع حقيقي.
- لا تستخدم النسخة لجمع بيانات حقيقية قبل مراجعة إعدادات الأمان والخصوصية واختبارها. وبما أن إعداد الدفع أو بعض الخدمات قد يتطلب صاحب حساب بالغًا، استعِن بولي أمرك عند الحاجة.

ملفات الحزمة:
index.html — الموقع
firebase-app.js — منطق المصادقة وقاعدة البيانات
firebase-config.js — تضع إعدادات مشروعك هنا
firestore.rules — قواعد الوصول لقاعدة البيانات
